# コントローラーだけで全操作するための洗い出し

2026-11-17。読み取り調査のみ（コード変更なし）。4 つの子エージェントの調査結果を司令塔チャットで統合し、主要な主張はコードで抜き取り確認した。
パスの接頭辞は `crates/bmz-player/src/`。

## 前提

- コントローラーのボタンに固定の意味はない。キーコンフィグで割り当てた鍵盤・皿・E1〜E4 として動く（[controls.md:39](../../docs/controls.md)、`app/scene_input.rs:139`）。
  - gilrs のボタン名は `ButtonN` / `AxisN±` だけで、Start / Back / D-pad の論理名は扱っていない（`input/gilrs.rs:350-360`）。
- 判定は 2 種類で行った。
  - 専コン：7 鍵＋皿＋E1〜E4。
  - 汎用パッド：余ったボタンをキーコンフィグで割り当てる前提。
- 入力の経路（`input/capture.rs:100-170`）
  - プレイ系：キャプチャスレッドで lane に解決し、ゲーム用キューへ入れる。
  - UI 系：frame ループの `consume_captured_gamepad_events`（`app/select_flow/gamepad.rs:4`）から `route_gamepad_button`（`:465`）へ進み、画面ごとに分岐する。
  - **egui（BMZ メニュー）にはパッド入力が一切届かない。** egui の入力は winit のキーボード・マウスだけ（`ui/runtime.rs:287`、`app/lifecycle.rs:115-119`）。
    例外はキーコンフィグの待ち受けだけ（`ui/runtime.rs:154`）。

## 既にコントローラーで足りている範囲

- 選曲
  - 移動、フォルダの出入り、決定、戻る
  - E1 / E2 / E1+E2 hold のオプション
  - TARGET、G-BATTLE（KEY4 長押し）
  - ランダム選曲、RANDOM MIX、未所持譜面の取得（IPFS / HTTP）
- 選曲画面の「設定」フォルダ（スキン内の設定）
  - 一覧の移動、値の増減、確定、取消。キーコンフィグでのパッドの割り当てもできる。
  - `screens/settings_edit.rs`、`app/select_flow/controls.rs:613-698`
  - **egui を使わずに済む、パッド対応の設定画面として最重要。**
- 決定画面：決定、キャンセル（E2+E1 / E2+E3）、ワンバス
- プレイ
  - HS、緑数字、レーンカバー量、LIFT / HIDDEN 切替、SUDDEN+ 表示
  - 中断、FAILED 中のクイックリトライ
- プラクティス：カーソル、値、開始、戻る
- リザルト
  - 退出、退出時のリトライ（KEY5 / KEY7 を押したまま）、ゲージグラフ切替（KEY6）
  - IR パネルの切替（E1 / E2）、IR 一覧のスクロール（皿）

### A. 根本：システム操作とメニュー

### D. 対象外にしてよいもの（案）

- ファイルのドロップ

## ついでに見つかった不一致

- リザルトの退出は、docs では「KEY1〜KEY4」（[controls.md:716](../../docs/controls.md)）。
  実装は KEY1 / 3 / 4 / 5 / 7 で、KEY2 を含まない（`app/result_support.rs:979-981`）。
- 通常の F1 メニュー表示中、パッド入力は選曲側へ通る（[controls.md:95](../../docs/controls.md) の仕様どおり）。
  パッドでメニューを操作できるようにするときは、この仕様を変える必要がある。

## オペレーターの決定（2026-11-17）

1. **専コン基準。** 7 鍵＋皿＋E1〜E4 だけで全部できるようにする。汎用パッドは、余ったボタンをキーコンフィグで割り当てて使う。
2. **BMZ メニューは設定フォルダへ移す。** パッドで動く選曲画面の設定フォルダに、足りない項目を足していく。egui にパッドの操作は足さず、パッドで閉じられるようにするだけ。
3. **文字入力は画面キーボードを作る。** 皿と鍵盤で文字を選ぶ。曲名の検索のため、かな入力も必要。
4. **OS のダイアログ（フォルダやファイルの選択）は対象外。** キーボード・マウス前提のまま。ファイルのドロップと CLI も対象外。

## 割り当て案（承認待ち）

空いているのは E4（選曲では未使用）と E3（対応スキンでの IR スコープ切替だけ）。プレイ中の E4 は E1 と同じ扱いのまま変えない。

### プレイ画面以外：E4 を「システムボタン」にする

| 入力 | 動作 | 画面 |
|---|---|---|
| E4 短押し（ほかを押さずに離す） | **クイックメニュー**を開く。その画面で使える操作の一覧で、皿で選び、奇数鍵で実行、偶数鍵・E2・E4 で閉じる | 選曲・リザルト・設定フォルダ・Viewer 待機 |
| E4 短押し（BMZ メニュー表示中） | BMZ メニューを閉じる | 全画面 |
| E4 hold ＋ E3 | スクリーンショット | プレイ以外の全画面 |
| E4 hold ＋ 皿 | ページ移動（選曲）、シーク（Viewer） | 選曲・Viewer |
| E4 hold ＋ KEY1〜7 | 画面ごとの近道（クイックメニューに近道として表示する） | 下表 |
| E4 を 1 秒長押し | キーコンフィグの待ち受けを取り消す（短押しは E4 自身の割り当てとして確定） | 設定フォルダ |

E4 hold 中は、E1 / E2 / E3 の本来の意味（パネル、IR スコープ切替など）を止める。

E4 hold ＋ KEY の近道：

| 画面 | KEY1 | KEY2 | KEY3 | KEY4 | KEY5 | KEY6 | KEY7 |
|---|---|---|---|---|---|---|---|
| 選曲 | 検索（画面キーボード） | ソート | キーモードフィルター | 難易度フィルター | お気に入り（曲） | お気に入り（譜面） | リプレイ再生 |
| リザルト | リプレイ保存 1 | 保存 2 | 保存 3 | 保存 4 | お気に入り（曲） | お気に入り（譜面） | OPEN IR |

クイックメニューにだけ置くもの：
- 選曲
  - 先頭 / 末尾へ、同じフォルダ、F3（フォルダを開く）、F5（再読み込み）、F10（Autoplay）、OPEN IR
  - ライバル切替、リプレイのスロット切替、キーコンフィグ、曲テキスト
  - G-BATTLE の固定表示、コース作成の保存・名前・直前の取消
  - BMZ メニューを開く、**終了**（確認つき）
- 設定フォルダ：割り当て解除、既定に戻す
- Viewer：一時停止、再読み込み、RANDOM の再抽選、先頭へ

## 設計上の注意（実装時）

- UI ナビゲーション層は、共通の `GamepadButtonEvent` より後（frame ループ側）に置く。
  そうすれば全バックエンドに効き、フォーカス喪失時の再同期（`app/input_runtime.rs:263-277`）にも乗れる。
- プレイ中は新しい UI 操作を無効にする。E1 / E2 hold の組み合わせ（`select_flow/gamepad.rs:507-526, 634-745`）と衝突させない。
- `select_flow/gamepad.rs` はほとんどの穴の分岐点になる。並行作業ではこのファイルの衝突に注意する。
